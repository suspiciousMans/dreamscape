# Stream WORLDGL (branch perf/worldgl, worktree /home/_l/dreamscape-perf/worldgl, CARGO_TARGET_DIR=/home/_l/dreamscape-perf/target-worldgl)
Goal: make `render()`'s 3D part (`rnd.world passes` 1.7 ms) and `present` (1.4 ms) cheaper with identical output. Code: `games/dreamscape/src/main.rs` `fn render` (the 4-pass loop, ~line 12877+), `engine/src/renderer/*`, `engine/src/mesh`, `engine/src/texture.rs`, `engine/src/shader`.
Known waste (verify each in the code):
- ~30 `gl.get_uniform_location(program, "name")` string lookups per frame: cache the locations per compiled program (struct built when the program is compiled/changes).
- Each of the 4 passes runs a full `world.query` over every entity with 10 component fetches, but pass 1 (outline shell) and pass 3 (silhouette) only want `Hero` entities and pass 2 only `Translucent`/water: collect once per frame into per-pass index lists (Vec reused across frames, no per-frame allocation), or query only the needed components.
- Per entity: 5 `uniform_1_f32`/matrix uploads and a texture bind even when unchanged: keep a tiny state cache (last lit/hero/melt/uv/texture) and skip redundant GL calls; sort draw lists by texture within a pass only if draw order does not change the picture (opaque pass 0 may be sorted by texture; alpha/silhouette passes must keep order).
- `mesh.draw` per block: look for repeated identical meshes (blocks) that could be drawn with fewer state changes; instancing only if it is simple and provably identical.
- The `present` path runs trail + composite each frame; skip the trail pass when `trail_amount` is 0 (check it already does) and avoid reallocating targets.
Measure with `perf::count` counters you add (draw calls, uniform calls, texture binds, entities visited per pass) printed by the profiler, before/after; and `perf::scope` timings are CPU-submit times you cannot run, so rely on the counters. Unit-test any pure helper (pass lists, state cache hit/miss logic: write the state cache as a small pure struct that returns "needs set" booleans). Output must be identical: do not reorder alpha-blended draws, keep the pass semantics (read the comments in the loop).
Own: the 3D part of render(), engine/src/renderer, mesh draw, a new `renderstate.rs`. Do NOT touch the egui/HUD part of render() or hud_view (UIPIXELS / LOADSPIKES).
