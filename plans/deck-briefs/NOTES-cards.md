- **Edges 8 -> 16** (`edges.rs`, `// === edges2 ===`): CLEAVE (Dawn, fan cos 0.1), LONGARM (Aether, reach x1.25), AMBUSH (Blank, +1 vs unaware), OPENER (Static, +1 on untouched foe), RIPPLE (Tide, foes within 2.5 of target reel 0.6s), LANTERN (Trace, every undone leaves a mote), PUNISHER (Gaze, +1 vs reeling), WINDFALL (Velvet, +2 dust per undone). Wired in main.rs `edges2` blocks (strike_reach, strike_arc_cos, strike_damage bonus, hurt_foe ripple, unravel loot). All numbers are consts.
- **Events 5 -> 17** (`events.rs`, `events2`): 12 new events, 14 new `Plan`s, resolving to existing `Applied` kinds only. Icons mapped in `event_icon`. NOTE: `pick` indexes a pool that is now larger, so which event an old seed shows changes (events are rolled on their own stream; nothing else shifts).
- **Achievements 29 -> 44**: 15 new (state + 2 event hooks), thresholds consts, Steam API names = ids (register in Steamworks), ACHIEVEMENTS.md updated. `steam.rs` needed no change (generic).
- **Companion**: not extended. The boon table is one passive per `Weight` (8 weights, a lore enum), so more boons need new weights (lore text).
- **UI side effect**: `power_lines` (loadout/merge/deck detail) now drops the flavour line for cards with an edge and tightens gaps; otherwise the extra edge row overflowed (`audit_text_fits_every_screen`). Existing edge cards (Rust, Abyss...) also lose their flavour line in those panels.
